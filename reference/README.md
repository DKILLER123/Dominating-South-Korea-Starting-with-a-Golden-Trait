## Hard firewall — the reader's standing instruction

> Don't use any character name or any things from *Peninsula: Going Viral After a Dating Scandal
> with Kim Taeyeon*. It's only for Skills & process needs to use for this book.

So from these files: **methods are legal, material is not.** No character, nickname, invented
company, label, song title, tour name, stat panel, chapter number, ship, group roster or
established date from that novel may appear in this book, in this book's documentation as fact, or
in a commit message presented as this book's canon.

Real-world overlap is not bleed: both serials are set in the real Korean entertainment industry, so
a shared public figure (an idol, an agency) is legitimate **only when this book's own raw names
them**. `python3 legacy_firewall.py` enforces exactly that split — hard tokens (the reference
novel's inventions) block a build, soft tokens (real public figures) are cleared only against
`raws/`.

`reports/firewall.json` is the standing proof, regenerated by every audit run.

## Reading order for a new cycle

1. `AGENTS.md` (this repository root)
2. `SKILL.md` (this book's playbook — the rules, already adapted)
3. `worklog.md` §0 and the newest §8 entry (this book's state)
4. only then, anything in this folder, for process precedent
